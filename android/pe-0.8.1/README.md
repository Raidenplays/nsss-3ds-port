# Pocket Edition 0.8.1 assets (reference for the Android version)

The interface textures (gui.png, spritesheet.png, touchgui.png...), font, sounds and language
files from Minecraft: Pocket Edition 0.8.1, for matching the old PE menus in the Android port.
Mojang's files, kept in this private repo for personal use only. Never publish them.
Only the game's own assets are here; the APK they came in was wrapped in an ad installer and
was not kept.
